1 · Add to Home Screen checking

Launched from Safari? Use the Share menu → “Add to Home Screen,” then open the icon. This card turns green when the app is running in standalone mode.

2 · Offline launch checking

The service worker precaches the app shell so it opens with no network. To verify: keep this installed, enable Airplane Mode, then relaunch from the home-screen icon — it should still load.

3 · Data survives force-quit manual

Write a record to IndexedDB, force-quit the app, relaunch, and confirm the write count and timestamp below are unchanged (i.e., it persisted).

4 · Geolocation manual

Tapping below should raise the location permission prompt and then resolve to coordinates.

5 · Camera / photo library manual

Should present the native camera/library chooser (no capture attribute, so you get the choice). Selected images preview below.

6 · Backup download / share sheet manual

Generates a JSON file via a blob download. On iOS this should raise the share sheet so you can save to Files / iCloud Drive.
